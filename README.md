# Farmflow
This is a full-stack multi-vendor e-commerce web application where multiple sellers can list products and multiple buyers can browse and purchase them.

👥 Users in the system:
Buyer
Seller
🛒 Seller Features
Register & login
Create store/profile
Add products:
Product name
Description
MRP (original price)
Discount %
Final price (auto-calculated)
Images
Stock quantity
Edit/Delete products
View orders placed on their products
🛍️ Buyer Features
Register & login
Browse all products from different sellers
Search & filter (price, category, discount)
View product details
Add to cart
Place order
View order history
⚙️ Core Functionalities
Authentication (JWT/session)
Role-based access (buyer vs seller)
Product management
Cart system
Order system
Price calculation:
Final Price = MRP - Discount
